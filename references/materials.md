# 材料核对

## 确认归属与去重

1. 有审批时，从正文核对审批编号、时间、事由、地点和审批结果。按实际消费或乘车日期匹配票据。发票开具日期留作票面信息。
2. 按发票号码和底层订单去重。PDF、OFD、XML 或邮件副本可能属于同一张发票。遇到更正或重开，按票面、订单及可核实的状态确认采用版本。状态不明时列出待确认票据。
3. 优先读票面和凭证明细。扫描件可用当前环境的 OCR，再核对识别易错的号码、日期和金额。以发票价税合计记录票面金额，另外记录拟报金额和差额依据。

## 配对

| 类别 | 配对依据 |
| --- | --- |
| 住宿 | 核对酒店、入住和离店时间、实付金额。按公司的凭证要求匹配住宿发票与水单或订单明细。 |
| 打车 | 核对发票和行程单中可对照的订单、实际日期、路线及金额。合并发票保留分段，按实际乘车日统计。 |
| 铁路 | 核对乘车日、车次、起讫站和实付。改签、退票相关费用单独识别，按适用规则决定材料要求。 |
| 航空 | 按出行人、航段和日期匹配电子凭证与行程。按适用规则补齐登机或支付凭证。 |
| 日常费用 | 用交易方、实际消费日期、金额和费用事由，与用户提供的订单或支付凭证配对。 |

用附加凭证支持对应费用，汇总时只计入实际费用。对照公司要求，将确定缺件、配对不明和规则待确认分别标注。有限额时按规定的日期和类别归集，列出涉及订单、可报金额和超限额。涉及拆分或重开时列出受影响的订单，由用户选择处理方式。

## 归档

经用户要求归档时，按已有结构落盘。遇到同名文件先核对内容，保留原件，给确需并存的文件取可辨识的新名。重新打开落盘文件核对，并返回实际路径。
