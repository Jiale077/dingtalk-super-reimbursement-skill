# 材料核对

## 确认归属与去重

1. 有审批时，从正文核对审批编号、时间、事由、地点和审批结果。按实际消费或乘车日期匹配票据。发票开具日期留作票面信息。
2. 按发票号码和底层订单去重。PDF、OFD、XML 或邮件副本可能属于同一张发票。遇到更正或重开，按票面、订单及可核实的状态确认采用版本。状态不明时列出待确认票据。
3. 优先读票面和凭证明细。扫描件可用当前环境的 OCR，再核对识别易错的号码、日期和金额。以发票价税合计记录票面金额，另外记录拟报金额和差额依据。

## 配对

| 类别 | 配对依据 |
| --- | --- |
| 住宿 | 核对酒店、入住和离店时间、实付金额。按公司的凭证要求匹配住宿发票与水单或订单明细。 |
| 打车 | 核对发票和行程单中可对照的订单、实际日期、路线及金额。合并发票保留分段，按实际乘车日统计。 |
| 高铁／火车 | 用电子发票（铁路电子客票）核对乘车日、乘车人、车次、起讫站和金额。发生改签或退票时，将原行程与改签或退票记录匹配，核对实际发生的手续费和退款。 |
| 飞机 | 用电子发票（航空运输电子客票行程单）或其他适用发票核对旅客、日期、航段和金额。按公司要求补登机凭证、订单或支付明细。改签、退票费或额外行李费有独立凭证时，单独核对对应航段与金额。 |
| 其他市内交通 | 地铁、公交、机场大巴等按票据和订单核对实际日期、线路和实付金额。 |
| 自驾／租车 | 按适用规则核对过路费、停车费、油费或租车费，对照车辆、使用日期、路线或租车订单。 |
| 餐费／招待／办公采购等 | 对照费用事由、交易方、实际消费日期和金额，按要求配对用餐或商品明细、订单、支付记录及审批。涉及餐费和差旅补助时分别列项，按公司规则核对可报范围。 |

区分主票据和补充凭证。航空电子客票行程单是机票的发票凭证，打车行程单用于说明打车发票对应的行程。多份单据对应同一笔消费时，核对退款和更正后只汇总一次。对照公司要求，将确定缺件、配对不明和规则待确认分别标注。有限额时按规定的日期和类别归集，列出涉及订单、可报金额和超限额。涉及拆分或重开时列出受影响的订单，由用户选择处理方式。

## 归档

经用户要求归档时，按已有结构落盘。遇到同名文件先核对内容，保留原件，给确需并存的文件取可辨识的新名。重新打开落盘文件核对，并返回实际路径。
