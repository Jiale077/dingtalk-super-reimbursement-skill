# 钉钉操作

参考 macOS 钉钉客户端。组织启用的功能、字段及标签以当前页面为准。用当前页面的控件和可见文本定位，切页与保存后重新读取状态。

## 导出审批

1. 在目标组织打开「工作台 → OA 审批」，在「我发起的」或实际可用入口搜索事由和日期。打开详情核对审批编号、类型、起止和状态。
2. 通过详情中的「下载为 PDF」或官方导出入口保存到目标目录。只有图标时结合当前截图辨认。macOS 的保存窗口可用 `⌘⇧G` 跳转目录。
3. 打开导出的 PDF，核对正文与完整审批流程。当前组织缺少导出入口时报告已查到的信息，并把官方 PDF 标为待补充。

## 查单和填写表头

1. 从「工作台 → 超级报销 → 报销单」进入。查现有报销单时，确认组织、筛选日期及分页覆盖目标。优先按报销单号查找，常见单号以 ER 开头。只有事由时，再用行程日期及审批编号缩小范围。多个匹配项无法区分时让用户指明。
2. 用户要求查状态时，记录实际单号和页面显示的状态。用户要求填单时，复用匹配的编辑中草稿。发现匹配的进行中或已完成单据时，报告它的状态并核实是否还有另一笔要报。
3. 用实际表单核对单据类型、事由、日期及所需城市。按适用要求关联审批或把 PDF 加入单据附件。分别核对报销人和费用归属部门，按已确认的公司规则和当次要求，选择准确的项目、费用部门和结算方式。
4. 新建流程中的「下一步」可能立即创建草稿。仅在已确定需新建时继续。出现新单后记录单号和状态，再录费用。若已有费用锁定表头字段，把该字段标为待处理并保留已有费用。

## 费用与附件

1. 先核对已录费用、已关联发票和系统生成的补助。用发票号码、实际日期、金额和费用编号确认已有行。只录入缺的费用或补充缺的附件。
2. 如当前页面提供「发票生成费用」，按要求选择适用发票，识别后核对张数、号码、抬头和金额。需要单张对应单笔费用时选「分别生成费用」或逐笔录入。发票夹已有对应发票时优先复用。
3. 按实际业务和组织可选项设置费用类型。核对识别后的默认日期，必要时改为实际发生日期。若表单要求住宿起止、出行城市或合并费用的日期范围，从已配对的凭证填写。
4. 将铁路电子客票、航空电子客票行程单等发票按当前表单的发票流程录入或关联。通过目标费用行的附件入口挂酒店水单、打车行程单、登机凭证等按要求补充的材料。审批 PDF 按要求关联或挂到单据层。分别核对发票预览、费用附件和单据附件三个位置。在文件选择窗口核对目录、文件名和目标费用后上传。
5. 附件出现在目标费用区后，保存当前费用。系统逐笔引导时依次核对和保存。回列表复开同一张单，确认状态、表头、明细数量、发票、日期、附件和系统合计。检查所补附件能否预览，并单独列出系统补助或差异。

中断后重新定位已记录的单号，按复开后可见的结果续填。交付时按实际情况区分复开核验通过、保存结果待核验和待填写项目。
