# 配图提示词

两张图均用内置图像生成工具制作。画风参考 [图文知识学习封面](https://github.com/Jiale077/illustrated-knowledge-skill/blob/main/docs/images/hero-jiale-ai-workshop.png)。

## 品牌封面

```text
绘制 Jiale 的 AI 工坊同系列的 GitHub README 品牌横幅。参考图是已经发布的「图文知识学习」封面，用于保持一致的构图、画风和小角色外观。画布为宽横幅，约 12:5，完整画面从顶部到底部均为暖白纸面 #F7F3ED，四周保留呼吸空间。

保留系列的视觉特征：自然粗炭黑墨线 #282B2D、橙色 #F36B40 强调、少量温和青绿色勾选、轻半调点纹、质朴的平面手绘墨线漫画。构图左侧约 34% 为文字，右侧 66% 为三个连续场景。画面要能在 GitHub 缩略宽度上看清。

左上角品牌逐字写「Jiale的AI工坊」，用和参考图相同的字重比例，品牌下方一短橙线。左边主标题分两行，逐字写第一行「钉钉超级」，第二行「报销助手」。标题用稳定粗黑中文无衬线，第一行下方有橙色手绘长下划线。副标题逐字写「从票据核对，到报销草稿。」。

右侧三步从左到右，用两段短橙箭头连接：
一叠有锯齿边的报销发票、行程单、带放大镜的核对清单，底部浅橙短标签「核对票据」。
和参考图同一造型的小角色，保留奶白圆头、两枚椭圆眼、右上橙色小方块及炭黑工装。小角色托着橙色夹板，把一张纸片放入抽象的报销表单，底部标签「填报销单」。
有两三条抽象明细线与小回形针的整洁草稿单，旁边有青绿色核验勾和一个小抽屉归档图形，底部标签「复核草稿」。

三幅物件沿同一基线，相同大小和清楚的轮廓。纸张只带抽象线条，无真实账号、数字、票面信息或复刻的产品界面。全部画面文字只允许上述品牌、标题、副标题和三个标签，按给出的字逐字正确渲染。要像参考图同一创作者制作的系列封面。
```

## 报销附件示意图

```text
绘制「Jiale的AI工坊」的 GitHub README 内文用工程图解，跟随所附品牌封面的暖白纸面 #F7F3ED、炭黑墨线 #282B2D、橙色 #F36B40 指引线及少量青绿色验证标记。16:9 左右的横向独立插画，有充足留白，配准清晰，用于手机阅读。这是可读的附件位置示意。

仅用一个居中的大报销单框解释两层位置，框上方的大标题逐字写「报销附件放哪里」。大框左边外侧纵向摆三张好分辨的文件卡，卡片短标签从上到下严格写「OA 审批」「酒店水单」「打车行程单」。线和箭头为橙色，三条水平方向一一对应，互不交叉。大框的内部布局如下：
- 顶部窄区写「单据层」，只有来自「OA 审批」卡片的箭头连到本区的一个回形针。
- 下部宽区的标题是「费用明细」，框中明确有两条不同的费用行。第一行仅写「住宿」，接收「酒店水单」的箭头。第二行仅写「打车」，接收「打车行程单」的箭头。每行只有一个回形针和一个小青绿勾。
房屋和小车可以画作很小的行内图标，流程关系通过行对齐和箭头表达。每个中文标签大而正确，逐字对照，总共只能出现标题和上述七个短标签，不加装饰文字、页码、金额、品牌名、真实界面或个人信息。读者扫一眼就能判断每份凭证进哪一层。
```
